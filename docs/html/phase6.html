1.3 Monorepo 结构

用户登录 POST /api/auth/login
→
auth-service 校验密码(BCrypt)
→
校验通过?
→
返回 20001
→
生成 Access Token (JWT TTL=2h) + Refresh Token (TTL=7d)
→
返回 Tokens
→
前端存储 AccessToken→内存 RefreshToken→Cookie
→
后续请求 Authorization: Bearer {token}
→
Gateway 全局过滤器 JWT验签(RSA256) 解析 userId+roles
→
透传 Header X-User-Id X-User-Roles
